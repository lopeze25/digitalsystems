Programmable 4-Bit Locker

This is a programmable four-button locker. You set a 4-letter code with buttons A–D, and it only unlocks when the same code is typed again.
Link to project: (CircuitVerse):

https://circuitverse.org/users/425489/projects/4bitprogrammablelocker

AI Use:

I used an AI help write and code this page.

How to use it:

  1. Press RESET. LOCK is off and MATCH is on (open).
  2. Click four letters (A, B, C, D). One V LED lights per letter.
  3. Press ENTER. The code is saved and LOCK turns on.
  4. Type the same four letters and press ENTER. LOCK turns off and MATCH turns on. A wrong code stays locked.
  5. While open, a new code and ENTER locks it again with the new code. RESET erases the code.

Importance and Topic:

Keypads on doors, safes, and phones all store what you type and compare it with a saved code. This fulfills the registers topic: one shift register holds the letters in order, a second shift register counts them, and a parallel-load register keeps the code.

Specifications:

The locker must keep the letters in the order typed (B D A C is not B A D C), accept exactly 4 letters, save the code on ENTER while open, and check it on ENTER while locked.

Problems leading to Design Choices/tradeoffs:

1. Order matters. A shift register keeps the letters in order with no pointer: each new letter enters P0 and the others move over one slot.

2. One click became several letters. The clock ticks many times during one click, so B became B B B. An edge detector (one flip-flop and one AND gate) turns each click into one pulse.

3. A 2 to 1 MUX instead of a 4 to 1. Each slot must hold, shift, or clear. The flip-flop’s enable does the hold, so the MUX only chooses between shifting and clearing. ENTER clears a typo.

4. Counting to 4 without a counter. A second shift register, V, fills like this: 1000, 1100, 1110, 1111), so four letters is one wire, V3. It blocks a 5th letter and stops ENTER from saving a short code.

5. One flip-flop decides save or check. An earlier version used a set-mode flip-flop and a separate unlock latch. The lock flip-flop L does both: ENTER saves when L = 0 and checks when L = 1.

6. A slot that never cleared. In testing, V2 stayed on after ENTER, so the next letter jumped to V3 and a full code could not be typed. Its MUX was missing the constant 0, and in CircuitVerse an unconnected input makes the flip-flop keep its old value.

7. Comparing. Only equal or not equal matters, so four 2-bit XNORs and one AND gate are enough.
